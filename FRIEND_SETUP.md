# Running Purrmiere

Everything ships in here already, engine and all effects included. You only need two free things
installed once.

## One time

1. **Git for Windows** from https://git-scm.com/download/win (default options are fine).
2. **Godot 4.7.2, the .NET / "mono" build for Windows**, from
   https://godotengine.org/download/archive/4.7.2-stable/. Unzip it anywhere; it is just an .exe,
   no install.
3. **Get this folder** (clone it, or unzip what was sent to you):
   ```
   git clone https://github.com/SkinErrorAlt/Purrmiere_Video_Editor.git
   ```

## Every time

Double-click **`Update and Play.bat`**. A small window gets the latest version and gives you a
**Play** button. The first time it asks where your Godot .exe is and remembers it after that.

No building or compiling: the engine is already built and included.
